# User-based рекомендации

Веб-приложение для задания 4: рекомендации продуктов по похожим предпочтениям пользователей (USER-BASED).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Задание 4

По матрице предпочтений (строки - продукты, столбцы - пользователи):

1. Считается косинусное сходство между пользователями.
2. Для неоценённых товаров (оценка `0`) предсказывается рейтинг:

```
Pr_a,i = r̄_a + Σ_u∈K (r_u,i − r̄_u) · cos(a, u) / Σ_u∈K |cos(a, u)|
```

- `r̄` - среднее **ненулевых** оценок пользователя;
- **R** - порог сходства: в `K` входят соседи с `cos(a, u) ≥ R`, у которых товар `i` оценён;
- **порог Pr** - товар рекомендуют только если `Pr ≥` порога;
- среди прошедших порог выбирается товар с наибольшим `Pr`.

3. Новый пользователь (все рейтинги `== 0`) → продукт с **наибольшим средним рейтингом** (MID по ненулевым оценкам). Порог Pr к cold start не применяется.

По умолчанию: `R = 0.6`, порог рекомендации `4`.

### Пример из методички

|     | U1 | U2 | U3 | U4 |
| --- | -- | -- | -- | -- |
| P1  | 5  | 5  | 4  | 5  |
| P2  | 5  | 5  | 3  | 0  |
| P3  | 5  | 5  | 5  | 5  |
| P4  | 5  | 0  | 2  | 0  |
| P5  | 0  | 5  | 1  | 0  |

В примере U4 можно исключить (кнопка «×»). Рекомендации:

- **U1** → **P5**
- **U2** → **P4**
- U3 - все товары уже оценены
