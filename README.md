# Косинусное сходство

Веб-приложение считает косинусное сходство по матрице предпочтений и находит **две самые близкие пары продуктов** и **две самые близкие пары пользователей**.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5174/](http://localhost:5173/).

## Как пользоваться

1. Заполните таблицу оценок (строки — продукты, столбцы — пользователи) или загрузите CSV.
2. При необходимости добавьте или удалите продукты и пользователей.
3. Нажмите **Рассчитать**.

Чем ближе значение к `1`, тем похожее профили оценок.

## Формула

```
cos(θ) = (A · B) / (‖A‖ · ‖B‖)
```

- **A · B** — сумма произведений координат: `Σ Aᵢ Bᵢ`
- **‖A‖**, **‖B‖** — длины векторов: `√(Σ Aᵢ²)`, через `Math.sqrt`

Вектор продукта — строка матрицы (оценки всех пользователей).  
Вектор пользователя — столбец (оценки всех продуктов).

Считаются все уникальные пары, затем берутся две с наибольшим `cos(θ)`.

## Формат файла

CSV, TSV или текстовый файл. Первая строка — пользователи, первый столбец — продукты:

```csv
,U1,U2,U3,U4,U5
P1,5,4,5,3,5
P2,5,5,5,3,5
P3,5,4,4,2,5
P4,5,3,5,0,3
P5,5,0,5,0,0
P6,4,5,5,3,1
```

Можно загрузить таблицу только из чисел — имена `P1…` и `U1…` подставятся сами. Пример файла можно скачать в интерфейсе.
