# Коэффициент уверенности Шортлиффа

Считает KU гипотезы по мере доверия (MD) и мере недоверия (MND). База правил загружается из файла, предположения E1 и E2 собираются из любых правил этой базы.

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Как пользоваться

1. Загрузите базу правил (**Загрузить файл**) или отредактируйте список вручную. Можно добавить правило кнопкой **+ Правило**.
2. В блоках **E1** и **E2** соберите посылки: правило из базы, MD / MND, при необходимости NOT. Связки между посылками — AND (MIN) или OR (MAX).
3. Выберите заключение («То»). Если у E1 и E2 одно и то же заключение, считается объединённый KU.
4. Результат пересчитывается сразу: шаги свёртки, KU каждого предположения и итог.

Пример из задания можно скачать как `rules.txt` и сразу загрузить обратно. **Сбросить пример** возвращает исходные пять правил и значения MD/MND.

| | |
|---|---|
| База правил | Любое число строк, не только две |
| E1 / E2 | До двух независимых предположений |
| Посылки внутри E | Сколько угодно, AND/OR/NOT |
| Объединение | Только если заключения совпадают |

## Формулы

```
MD1 AND MD2 = MIN(MD1, MD2)
MD1 OR MD2  = MAX(MD1, MD2)
NOT MD1     = 1 − MD1

MD[H:E1,E2]  = MD[H:E1] + MD[H:E2](1 − MD[H:E1])
MND[H:E1,E2] = MND[H:E1] + MND[H:E2](1 − MND[H:E1])
KU[H:E]      = MD[H:E] − MND[H:E]
```

Несколько посылок сворачиваются слева направо: каждая следующая связка применяется к уже полученному значению. То же самое для MD и MND. Если включено только одно предположение, итоговый KU — его собственный.

MD и MND — числа от `0` до `1`. KU лежит в `[-1, 1]`: плюс — гипотеза скорее подтверждается, минус — скорее опровергается.

## Формат файла

TXT, CSV или TSV. Одно правило на строку; в таблице берётся первый столбец. Пустые строки и строки, начинающиеся с `#`, пропускаются. Первая строка `правило` / `rule` считается заголовком и не попадает в базу.

```txt
X проживает в Y
X является членом партии Z
X имеет возраст T
X является ИП
X будет голосовать за кандидата B
```

CSV то же самое:

```csv
правило
X проживает в Y
X является членом партии Z
```
