# Косинусное сходство

Веб-приложение считает косинусное сходство по матрице предпочтений, находит **две самые близкие пары продуктов** и **две самые близкие пары пользователей**, затем строит **иерархические кластеры** по порогу R.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Как пользоваться

1. Заполните таблицу оценок (строки — продукты, столбцы — пользователи) или загрузите CSV.
2. При необходимости добавьте или удалите продукты и пользователей.
3. Задайте порог кластера **R** (по умолчанию `0.85`).
4. Нажмите **Рассчитать**.

Чем ближе значение к `1`, тем похожее профили оценок.

## Формула

```
cos(θ) = (A · B) / (‖A‖ · ‖B‖)
```

- **A · B** — сумма произведений координат: `Σ Aᵢ Bᵢ`
- **‖A‖**, **‖B‖** — длины векторов: `√(Σ Aᵢ²)`, через `Math.sqrt`

Вектор продукта — строка матрицы (оценки всех пользователей).  
Вектор пользователя — столбец (оценки всех продуктов).

Считаются все уникальные пары, затем берутся две с наибольшим `cos(θ)`.

## Кластеризация

После косинусов строится матрица расстояний: диагональ `0`, остальные ячейки — сходство пар. На каждом шаге ищется **максимум** в верхнем треугольнике (жёлтая ячейка).

- Если максимум **≥ R**, два кластера объединяются.
- Равенство порогу тоже считается объединением (`0.85 == R`).
- Сходство новых кластеров — **максимум** попарных сходств исходных объектов (single-linkage).
- Если максимум **< R**, объединение останавливается.

Исходная матрица косинусов не переписывается: после склейки таблица собирается заново. Новая ячейка между группами A и B:

```
sim(A, B) = max { cos(u, v) | u ∈ A, v ∈ B }
```

Кластеры считаются отдельно для пользователей (столбцы) и для продуктов (строки). В интерфейсе видны все шаги перестройки матрицы и итоговые группы.

## Формат файла

CSV, TSV или текстовый файл. Первая строка — пользователи, первый столбец — продукты:

```csv
,U1,U2,U3,U4,U5
P1,5,4,5,3,5
P2,5,5,5,3,5
P3,5,4,4,2,5
P4,5,3,5,0,3
P5,5,0,5,0,0
P6,4,5,5,3,1
```

Можно загрузить таблицу только из чисел — имена `P1…` и `U1…` подставятся сами. Пример файла можно скачать в интерфейсе.
