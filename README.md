# Item-based рекомендации

Веб-приложение для задания 5: рекомендации продуктов по похожим предпочтениям товаров/услуг (ITEM-BASED).

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Задание 5

По матрице предпочтений (строки - продукты, столбцы - пользователи):

1. Считается косинусное сходство между **товарами** (строками).
2. Для неоценённых товаров (оценка `0`) предсказывается рейтинг:

```
Pr_a,i = Σ_j∈K r_a,j · cos(i, j) / Σ_j∈K |cos(i, j)|
```

- **R** - порог сходства: в `K` входят оценённые пользователем товары `j` с `cos(i, j) ≥ R`;
- **порог Pr** - товар рекомендуют только если `Pr ≥` порога;
- среди прошедших порог выбирается товар с наибольшим `Pr`.

3. Новый пользователь (все рейтинги `= 0`) → продукт с наибольшим средним рейтингом (MID).
По умолчанию: `R = 0.85`
