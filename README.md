# Хранение разреженных матриц

Веб-приложение для задания 3: три формата хранения разреженной матрицы предпочтений и фильтрация данных.

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:5173/](http://localhost:5173/).

## Задание 3

### Фильтрация

Из матрицы предпочтений убираются:

- товары с **нулевым** рейтингом (все оценки `== 0`);
- товары с **низким** рейтингом (среднее ненулевых оценок `< 4`, порог настраивается);
- **неактивные** пользователи (все оценки `== 0`).

Пример из методички — матрица 0 → матрица 1:

|     | U1 | U2 | U3 | U4 | U5 | MID |
| --- | -- | -- | -- | -- | --- | --- |
| P1  | 5  | 4  | 5  | 0  | 5  | 4,8 |
| P2  | 5  | 5  | 5  | 0  | 5  | 5,0 |
| P3  | 5  | 4  | 4  | 0  | 5  | 4,5 |
| P4  | 4  | 3  | 4  | 0  | 3  | 3,5 → удалить |
| P5  | 0  | 0  | 0  | 0  | 0  | 0 → удалить |
| P6  | 4  | 5  | 5  | 0  | 1  | 3,8 → удалить |

U4 неактивен → после фильтрации остаются P1–P3 и U1, U2, U3, U5.

### Структуры хранения

1. **COO** — `value`, `row`, `col`: тройки для каждого ненулевого элемента.
2. **CSR** — `value`, `col`, `rowIndex`: сжатие по строкам; `rowIndex[i]` — начало строки `i`.
3. **ELLPACK** — две матрицы `value` и `column` шириной `max(nnz в строке)`, короткие строки дополняются нулями.

Структуры пересчитываются для текущей матрицы в таблице.
